# MLS Housing Market Analytics

## Overview
Working on real estate market analytics using MLS transaction data as part of my Data Analyst Internship at IDX Exchange.

This project focuses on:
- Data cleaning and validation
- Feature engineering
- Housing market trend analysis
- Market performance metrics
- Time-series analysis

## Key Metrics
- Price Ratio
- Price Per Sq Ft
- Days on Market
- Close-to-Original List Ratio
- Listing-to-Contract Days
- Contract-to-Close Days

## Current Work
Completed:

Currently Working On:

- Feature Engineering

Later, I will be working on the following:
- Tableau dashboard development

- Housing market trend visualization

## Tools Used
- Python

## Business Focus
- Analyzing housing market trends, pricing behavior, inventory movement, and transaction efficiency to identify meaningful real estate insights and support data-driven decision-making.

- Building interactive Tableau dashboards to visualize market trends, pricing patterns, sales activity, geographic comparisons, and competitive performance across residential properties.
